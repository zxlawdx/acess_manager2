# Juniper / Junos BNG research

Target: MX traditional BNG, with no real model/release/credentials supplied. Research is not physical validation. Sources reviewed during this implementation:

| Official source | Finding / implementation decision |
|---|---|
| [show subscribers](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-subscribers.html) | user-name filtering on M120/M320/MX, address and id filters, count, extensive fields; query each known username, never dump all sessions |
| [PPPoE interfaces](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-pppoe-interfaces.html) and [PPPoE sessions](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-pppoe-sessions.html) | Interface detail can provide session/remote MAC/underlying/uptime; use selected interface, not global sessions |
| [AAA subscribers](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-network-access-aaa-subscribers-command.html) | session-id detail introduced in 17.3; lazy read, independent permission/schema errors |
| [Clear AAA subscriber](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/clear-network-access-aaa-subscriber.html) | Repeated usernames require session selection; no mutation shipped without release/permission/read-back/Windows prerequisites |
| [NETCONF SSH](https://www.juniper.net/documentation/us/en/software/junos/netconf/topics/topic-map/netconf-ssh-connection.html) | NETCONF over SSH, normally 830 if enabled; never configure the router to enable it |
| [NETCONF operational requests](https://www.juniper.net/documentation/us/en/software/junos/netconf/topics/task/netconf-requesting-operational-information.html) | Native RPC mapping is release-aware; display xml rpc on target is authoritative |
| [ncclient Junos command implementation](https://github.com/ncclient/ncclient/blob/v0.7.0/ncclient/operations/third_party/juniper/rpc.py) | Documented library command wrapper emits XML command element; Junos returns NCElement.data_xml, covered with actual ncclient wrapper test |
| [Juniper YANG subscriber catalog](https://github.com/Juniper/yang/blob/master/16.1/operational/show-subscribers.yang) | get-subscribers user-name/address/id/client-type/display; catalog reference, not a tested P1 wire capture |
| [Juniper YANG PPPoE catalog](https://github.com/Juniper/yang/blob/master/16.1/operational/show-pppoe.yang) | get-pppoe-interface-information, underlying-interface-name, session-id, remote-mac |
| [Juniper YANG AAA catalog](https://github.com/Juniper/yang/blob/master/16.1/operational/show-network-access.yang) | get-aaa-subscriber-table username/RI; newer session-id options require release confirmation |
| [Subscriber VLAN guide](https://www.juniper.net/documentation/us/en/software/junos/subscriber-mgmt-vlan/subscriber-mgmt-vlan.pdf) | Dynamic interfaces/profiles, ACI/ARI and lockout are distinct; no configuration mutation |
| [Subscriber sessions guide](https://www.juniper.net/documentation/us/en/software/junos/subscriber-mgmt-sessions/subscriber-mgmt-sessions.pdf) | AAA/RADIUS and dynamic profile statistics; absent/zero accounting does not prove no traffic |
| [Feature Explorer: PPP/PPPoE](https://apps.juniper.net/feature-explorer/feature/6643?fn=PPP%2FPPPoE+subscriber+interfaces) | MX204 baseline differs from MX240/480/960 and requires platform/release/licensing checks |
| [PPPoE overview](https://www.juniper.net/documentation/us/en/software/junos/subscriber-mgmt-vlan/topics/concept/subscriber-management-pppoe.html) | Concentrator/subscriber model; Evolved/redundancy support differs by platform/release |
| [Chassis hardware](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-chassis-hardware.html), [Routing engine](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-chassis-routing-engine.html), [Uptime](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-system-uptime.html) | Lazy chassis/RE resource reads; namespaces vary; Evolved uptime differs; missing values remain null |
| [Ping](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/ping.html), [Traceroute](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/traceroute.html) | Explicit source Juniper, typed destination/RI, bounded packet/hop count. Evolved ping RI limited to mgmt_junos |
| [RADIUS server status](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-network-access-aaa-radius-servers.html), [Lockout](https://www.juniper.net/documentation/us/en/software/junos/cli-reference/topics/ref/command/show-pppoe-lockout.html) | Researched, not shipped; no shared secrets or automatic clear lockout |
| [Logs](https://www.juniper.net/documentation/us/en/software/junos/network-mgmt/topics/topic-map/displaying-system-log-files.html), [Access routes](https://www.juniper.net/documentation/us/en/software/junos/subscriber-mgmt-access/topics/topic-map/subscriber-access-network-routes.html) | Optional future bounded/contextual reads; no log or route table dump shipped |

vMX was investigated as a lab candidate; no official release-specific proof for the owner's target was available. Do not inherit all physical MX capabilities just from the family string. No copied third-party implementation; ncclient is a runtime dependency. Fixtures are synthetic structures inspired by the published field/catalog descriptions, explicitly not physical outputs.
