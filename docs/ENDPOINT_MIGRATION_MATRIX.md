## 4. Regras de promoção para a nova arquitetura

- Paths/resources são conhecimento de infraestrutura, não API pública do frontend.
- A UI usa `/api/device/*` e `/api/profiles/*`; protocol details ficam atrás do provider.
- Uma mutation só fica habilitada quando a capability da feature é `SUPPORTED`. `PARTIAL` continua visível como evidência, mas não é executado por profile/apply automático.
- Timeout de mutation não gera retry cego. Read-back/estado incerto permanece responsabilidade explícita do writer/provider.
- Operações que no legado existiam apenas em fluxo experimental permanecem não promovidas até existir evidência suficiente.
