# Open-source references

This implementation uses Three.js 0.180.0 (`three` npm package), MIT, https://github.com/mrdoob/three.js/tree/r180. Its bundled GLTFLoader handles optional local models and AnimationMixer drives available idle/walk/run/jump clips. The package's complete MIT notice is retained in THREE_LICENSE.txt.

Player movement, damped camera, procedural environment, minimap, bridge and audio manager are original project code. No code or assets from the other repositories or Sketchfab pages listed in the supplied research documents have been copied. Those entries remain research candidates and must be inspected at a fixed revision with their actual licenses before reuse.
